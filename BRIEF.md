# My Links - Project Brief
A professional link-in-bio page. One page, clean design, mobile-first.
I want to send people here from our social profiles.

## Tech
- Pure HTML, CSS, and JavaScript - no frameworks, no build tools
- Single index.html file (CSS and JS can be separate files)
- Deploys to Vercel as a static site

## Design
- Centered card layout, max-width 480px
- My name as a heading, short bio underneath
- Profile photo placeholder (circle, 120px)
- Dark mode by default with a light/dark toggle
- Smooth hover animations on the link buttons
- Google Font: Inter
- Use colors associated with the brand styling

## Links
- Display these as stacked buttons, full-width within the card:
- Portfolio (https://www.safdiearchitects.com)
- LinkedIn (https://www.linkedin.com/company/safdiearchitects/)
- Instagram (https://www.instagram.com/safdiearchitects/?hl=en)
- Email (hello@safdiearchitects.com)

## Nice to Have
- Subtle or animated background
- Link buttons have icons (use simple SVG or emoji)
- Footer with "Made with flair"
